# Наступний прохід для ChatGPT

Вставити цей текст у координаційний чат ChatGPT. Вердикти за кожною моделлю описані в [REVIEW.md](REVIEW.md), стильовий замок має пріоритет над текстом промптів.

## Загальні правила

- Лише **світлий** варіант, **один** на модель/ракурс, без темних версій.
- Кожну модель продовжуй у її **архівованому чаті** (id нижче): відновити чат і писати там, нового чату не створювати.
- Файли зберігай із тими самими назвами в `art/concepts/<id>/` (`side.png`, `back.png`, `portrait.png`). Нічого більше не змінюй і не перейменовуй.
- Формат 1:1, один об'єкт, рівний світло-сірий фон, без тіні, тексту й рамки.
- Нічого тонкого й прозорого навколо фігури: ні диму, ні туману, ні розвіяних пасом волосся, ні бахроми. Одяг не нижче колін.
- **Усі ракурси однієї моделі мають мати ту саму позу й той самий дизайн, що й затверджений фронт** (Meshy Multi-View).
- Гуманоїди на боці: руки **прямо вздовж тулуба в одній лінії з плечем**, лікоть не зігнутий уперед, кисть збоку від стегна, а не перед животом чи поясом. На спині: A-поза, як на фронті, руки порожні.
- Дизайн, кольори, одяг, предмети (кристали, торбини, колчан, жорно тощо) не змінювати. Якщо чогось не видно з іншого боку, домалюй його логічно, не вигадуй нових деталей.
- Після кожної моделі допиши у `art/concepts/REPORT.md` один рядок: що зроблено.

Текст запитів ті самі, що й у файлах промптів моделі (`art/prompts/<тип>/<id>.md`):

- **side:** `Show exactly the same character with identical design, colors, proportions and A-pose, seen from the left side. Same background and lighting.`
- **back:** `Show exactly the same character with identical design, colors, proportions and A-pose, seen from behind. Same background and lighting.`
- **portrait:** `Portrait bust of exactly the same character, same style and colors, facing slightly to the side, soft neutral background, square 1:1, for a game UI icon.`

Для істот (пацюк, вовк, Ґудзик, слиз, привид) у цих фразах «character» → «creature», «A-pose» → «pose».

### 4. Не чіпати

`wind-archer` (усі ракурси), `cellar-rat`, `gremlin`, усі зброя, пропси й текстури: прийняті.
