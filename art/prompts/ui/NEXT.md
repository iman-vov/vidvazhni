# Наступні завдання для ChatGPT (UI), станом на 2026-10-24

Уже зроблено: `main-menu`, `scenario-hud`, `ability-card`, логотипи, `card-frames`. Результати `card-frames` поклади в `art/ui-mockups/card-frames/`.

Загальні правила, стиль A і стиль B — у [README.md](README.md). Гібрид: тло зі стилю A, панелі, кнопки й логотип зі стилю B.

**Зміни, які треба врахувати в описах екранів у README:**
- місто тепер називається **Альба**, корчмарка — **пані Марта**;
- «місто», «крамниця» й «аркуш героя» зливаються в один екран **табору**, як у Jaws of the Lion;
- в ініціативі тепер є **кубик**: число на карті плюс кидок дає підсумок.

Порядок (від найважливішого):

| № | id | Що намалювати |
|---|---|---|
| 1 | `icon-sheet` | Як у README (№15). Додай ще іконки: **кубик** (ініціатива), **перекидання**, **скриня**, **золото**, **ціль місії** (прапорець), **супровід** (NPC), **захист точки** (вежа), **важіль**. Це головне: за цим аркушем ми намалюємо власні SVG. |
| 2 | `camp` | Табір між місіями в Альбі. Ліворуч колонка портретів героїв, у центрі вкладки «Спорядження» (слоти голова, тіло, ноги, руки ×2, мале ×2; скриня героя; скриня загону), «Крамниця» (полиці, ціна в золоті, кнопка ★ покращити), «Рівень» (нова карта: одна з двох; перк). Праворуч — [До місії ▸]. Зверху золото героя. Пані Марта з ліхтарем у куточку. |
| 3 | `dice` | Дизайн **кубика ініціативи** й анімації кидка на панелі ініціативи: карта «45» + кубик «7» = «52», порядок ходу героїв і монстрів у рядок. Окремо кнопки «перекинути» й «обрати кращий із двох» (дає спорядження). |
| 4 | `scenario-end` | Як у README (№12): перемога чи поразка, здобич (золото, предмети зі скринь і від особливих ворогів), досвід кожного героя, кнопка [До табору]. |
| 5 | `campaign-map` | Мальована карта краю з **розгалуженнями**: пройдені місії, доступні, закриті іншим вибором (сіра стежка), точка вибору (роздоріжжя з табличкою). 4 акти. |
| 6 | `objectives` | Плашка цілі місії на екрані сценарію для різних типів: «Вбий усіх», «Супроводь Ліну до виходу», «Захищай млин 5 раундів», «Збери 3 кристали», «Втечи». Іконка, короткий текст, лічильник. |
| 7 | `pass-curtain`, `pause-menu`, `settings` | Як у README (№5, 6, 11). У налаштуваннях вкладка **«Правила»** з перемикачами наших механік (усі ввімкнені): кулі стихій, наміри монстрів, кубик ініціативи, Підхоплення, Наснага, Підняти друга. |

Екран `new-game` уже побудовано в грі, тож макет не потрібен. `hand-select` теж є в грі.
